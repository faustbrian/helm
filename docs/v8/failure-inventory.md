# V8 Failure Inventory

This inventory records failures found while exercising v8 as a real local
development environment. It is deliberately separate from the completion
matrix: fixing one symptom does not prove the associated release criterion.

Status meanings:

- `Fixed locally` means the production path and focused regression tests are
  present and the local verification suite passes.
- `Implementation CI passed` refers to the complete multi-architecture
  [implementation CI run][implementation-ci], which exercised the production
  baseline through FI-48 at selected candidate `0ca1db6` and retained its own
  artifacts.
- `Exact-candidate release evidence passed` refers to the candidate's complete
  [release workflow record][release-evidence].
- `External evidence pending` means the remaining behavior crosses an OS or
  physical-host boundary that repository tests cannot honestly prove.
